# 전극 슬러리 코팅 SOP v1.1 (내부)

## 목적
코팅 두께·건조 온도를 표준화하여 용량 편차와 도막 불량을 줄인다.

## 표준 조건
- 코팅 두께: 80–120 μm
- 건조 온도: 90–110°C
- 라인 속도: 1.5–2.5 m/min

## 이상 시 조치
1. 두께가 하한을 밑돌면 슬러리 점도·노즐을 점검한다.
2. 건조 온도가 110°C를 초과하면 즉시 출력을 낮춘다.
3. 핀홀·줄무늬가 반복되면 LOT를 보류하고 품질 팀에 통보한다.

## 보안
본 문서는 사내 내부용이다. 외부 반출을 금지한다.
