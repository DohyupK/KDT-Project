# 금속 불순물 관리 매뉴얼 v1.0 (내부)

## 목적
원료·공정 중 금속 불순물(metal_impurity) 유입을 통제하여 불량률을 낮춘다.

## 기준
- 허용 상한: 0.02 wt% 이하
- 경보: 0.015 wt% 초과 지속
- 샘플링: LOT당 최소 2회

## 이상 시 조치
1. 경보 시 해당 배치 원료를 격리하고 재분석을 의뢰한다.
2. 혼합·코팅 설비의 마모 파편을 점검한다.
3. 연속 경보 시 생산 라인을 보류한다.

## 보안
사내 내부용. 외부 반출 금지.
