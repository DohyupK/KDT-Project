# 공정 습도 관리 매뉴얼 v1.0 (내부)

## 관리 범위
혼합·소성 전 구간의 상대 습도를 관리한다.

## 기준
- 권장 상대 습도: 35–45%
- 경보: 50% 초과 지속 30분 이상
- 기록: LOT별 습도 로그를 필수 첨부

## 대응
1. 제습기를 기동하고 외기 유입 밸브를 점검한다.
2. 습도 경보 중에는 신규 리튬 투입을 보류한다.
3. 관련 SOP(소성)와 교차 확인한다.

## 보안
사내 규정 문서. 클라우드 LLM/외부 전송 금지.
