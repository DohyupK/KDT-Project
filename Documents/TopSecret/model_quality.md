# 모델 품질 · voting `temp` vs CSV

최종 갱신: 2026-08-10  
관련: cascade voting · MariaDB `` `temp` `` · [`docs/references/multi-model-voting.md`](../../docs/references/multi-model-voting.md)

이 문서는 **투표 앙상블 예측**(`temp`)과 **원본 CSV 실측**의 정합을 모은다.  
Public [`model_quality.md`](../Public/model_quality.md)와 동일 형식 · **슬라이스·모델은 voting 재채점 결과**.

---

## 0. 임계값 (모델이 불량으로 칠 때)

| 항목 | 값 | 근거 |
|------|-----|------|
| 운영·평가 임계값 | **0.4 (40%)** | `ai-service/models/voting_config.json` → `threshold.default_threshold` |
| 규칙 | `probability >= 0.4` → `quality_defect` = 1 | `voting_predict.py` (마지막 단계) |

CSV의 `quality_defect`는 이미 0/1 타깃이다.  
아래 「예측」은 **저장된 probability에 임계값 규칙을 적용한 결과**이다.  
회귀(capacity · residual_li)는 임계와 무관.

## 3. 「≥0.4면 실제 불량인가?」

**부분적으로만 성립.**

`probability ≥ 0.4`인 **2503건** 안에서:

| 실제 (CSV) | 건수 | 비율 |
|------------|------|------|
| **1 (불량)** | 741 | **29.60%** |
| **0 (정상)** | 1762 | **70.40%** |

`probability < 0.4`인 **7497건** 안에서는 실제 1이 **125건 (1.67%)**.

→ 양성 예측의 약 **30%**만 CSV 불량(정밀도↓). 음성일 때 정상일 가능성은 높음.

|  | 실제 1 | 실제 0 |

| **예측 1** | TP 741 | FP 1762 |

| Accuracy | 0.8113 |
| Precision | 0.2960 |
| Recall | 0.8557 |

| Pearson(r) prob ↔ actual | 0.5266 |

| 연관 지표 | 값 |
|-----------|-----|
| 예측 양성률 | 25.03% |
| **실제** 불량률 (CSV) | **8.66%** (866/10000) |
| 실제=0 평균 probability | 0.2090 |
| 실제=1 평균 probability | 0.7114 |

→ 연관은 분명하나, 0.4 임계는 이 슬라이스에서 **과다 양성**(예측 불량률 ≫ 실제 불량률).

### `temp.quality_defect` vs CSV / vs 재계산

| 비교 | 일치 건수 |
|------|----------|
| `temp.quality_defect` ↔ CSV `quality_defect` | **8113 / 10000** (Accuracy 0.8113, 곧 ≥0.4 규칙과 동일) |
| `temp.quality_defect` ↔ `(prob ≥ 0.4)` | **10000 / 10000** |

(채점 시 임계 0.4로 기록된 컬럼과 probability 재적용이 완전 일치.)
