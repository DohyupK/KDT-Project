### 지표 정의

| 열 | 정의 |
|----|------|
| 임계값 | `probability ≥ T` 이면 검사(예측 양성) |
| 검사 LOT 수 | 예측 양성 건수 (TP+FP) |
| 검사 비율 | 검사 LOT 수 / 10000 |
| 불량 포착률 | Recall = TP / (TP+FN) = 잡은 실제 불량 / 전체 실제 불량(866) |
| 정밀도 | Precision = TP / (TP+FP) = 검사분 중 실제 불량 비율 |
| 놓친 불량 수 | FN = 실제 불량인데 임계 미만 |
| Accuracy | (TP+TN) / 10000 |
| F1 | 2·Prec·Rec / (Prec+Rec) |
