## 3. 「0.4 이상이 실제 불량인가?」

**부분적으로만 맞다.** 임계값 0.4는 실제 불량을 **잘 잡지만(높은 재현율)**, 정상도 많이 불량으로 올린다(정밀도↓).

예측이 양성(`prob ≥ 0.4`)인 **2267건** 중 실제 불량은 **790건 (34.85%)**.  
→ 「0.4 이상이면 반드시 불량」은 성립하지 않음.  
다만 예측 음성(`prob < 0.4`) **7733건** 중 실제 불량은 **76건 (0.98%)** 뿐이라, **음성일 때 정상일 가능성은 매우 높음**.

| 구분 | 실제 불량률 |
|------|-------------|
| `probability ≥ 0.4` (예측 불량) | **34.85%** (790/2267) |
| `probability < 0.4` (예측 정상) | **0.98%** (76/7733) |

## 5. 연관관계 (연속 확률 vs 실제 0/1)

| 지표 | 값 |
|------|-----|
| 전체 평균 probability | 0.2342 |
| 예측 양성 비율 (`≥0.4`) | **22.67%** |
| **실제** 불량 비율 (CSV) | **8.66%** |
| 실제=0일 때 평균 probability | **0.1834** |
| 실제=1일 때 평균 probability | **0.7701** |
| Pearson(r) probability ↔ quality_defect | **0.5941** |

→ 실제 불량 LOT의 평균 확률이 정상보다 **훨씬 높고**, 상관계수 ~0.59로 **양의 연관**이 분명히 있다.  
동시에 예측 양성률(22.7%)이 실제 불량률(8.7%)보다 높아, **0.4 임계값은 이 슬라이스에서 공격적(과다 불량 판정)** 이다.

## 6. judgment_lots.quality_defect vs CSV

같은 10000행에서 `judgment_lots.quality_defect`와 CSV `quality_defect`는  
**10000건 모두 일치** (disagree 0).

→ 이 구간 DB 판정 컬럼은 CSV 라벨과 동일 출처(시드/동일 라벨)로 보는 것이 맞고,  
「prob≥0.4로 만든 예측」과는 별개다. (현재 DB `quality_defect` ≠ 「지금 임계값을 probability에 다시 적용한 결과」와 같을 필요는 없음 — 여기는 일치율이 CSV와 100%.)
