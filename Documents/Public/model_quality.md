## 0. 임계값 (모델이 불량으로 칠 때)

| 항목 | 값 | 근거 |
|------|-----|------|
| 운영·평가 임계값 | **0.4 (40%)** | `ai-service/models/ensemble_config.json` → `default_threshold` · `metadata.json` → `applied_eval_threshold` |

## 3. 「≥0.4면 실제 불량인가?」

**부분적으로만 성립.**

`probability ≥ 0.4`인 **2267건** 안에서:

| 실제 (CSV) | 건수 | 비율 |
|------------|------|------|
| **1 (불량)** | 790 | **34.85%** |
| **0 (정상)** | 1477 | **65.15%** |

`probability < 0.4`인 **7733건** 안에서는 실제 1이 **76건 (0.98%)** 뿐.

→ 양성 예측의 약 1/3만 CSV 불량(정밀도↓). 음성일 때 정상일 가능성은 매우 높음.

## 4. 혼동행렬 · 성능 (예측 = prob≥0.4)

|  | 실제 1 | 실제 0 |
|--|--------|--------|
| **예측 1** | TP 790 | FP 1477 |
| **예측 0** | FN 76 | TN 7657 |

| 지표 | 값 |
|------|-----|
| Accuracy | 0.8447 |
| Precision | 0.3485 |
| Recall | 0.9122 |
| Specificity | 0.8383 |
| F1 | 0.5043 |
| Pearson(r) prob ↔ actual | 0.5941 |

| 연관 지표 | 값 |
|-----------|-----|
| 예측 양성률 | 22.67% |
| **실제** 불량률 (CSV) | 8.66% |
| 실제=0 평균 probability | 0.1834 |
| 실제=1 평균 probability | 0.7701 |

→ 연관은 분명하나, 0.4 임계값은 이 슬라이스에서 **과다 양성**(예측 불량률 ≫ 실제 불량률).

| 0.4–0.5 | 421 | 8.31% | 91.69% |
| 0.5–0.6 | 366 | 14.75% | 85.25% |

## 7. 한 줄 요약

1. 라벨링 임계값(예측 O/X)은 **40%**.  
2. `≥0.4` 표본의 **실제 불량은 약 35%**, 정상은 약 **65%**.  
3. 확률↑ → 실제 불량 비율↑ (연관 O). 다만 0.4는 재현율↑·정밀도↓.  
4. 대시보드 「불량률」이 `judgment_lots.quality_defect`를 쓰면, 이 슬라이스에서는 CSV와 동일 라벨이나, **08-05 이후 급증**은 score로 채워진 **모델 판정** 구간과 섞여 있을 수 있음(10001행 이후 등).
