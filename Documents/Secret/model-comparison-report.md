## 4. 병렬 vs 블렌딩 (개념만)

| | 의미 | 현재 |
|--|------|------|
| model0/1/2 | 같은 O/X · 다른 데이터 → **비교** | 점수 **합치지 않음** |
| 3헤드 병렬 | clf · capacity · residual 동시 추론 | 운영 채점에 사용 |
| 점수 블렌딩 | `α·p_clf + β·…`로 **최종 p 하나** | **설계 메모만** · 미구현 |

확률 구하기(추론) ≠ 블렌딩. 블렌딩은 이미 나온 점수를 섞는 후처리.
