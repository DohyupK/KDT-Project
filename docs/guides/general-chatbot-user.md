# 일반 상담 챗봇 — 사용자 가이드

최종 갱신: 2026-08-19

화면 오른쪽 아래 아이콘으로 여는 **일반 상담** 사용법입니다.  
기밀·보안 문서는 [보안 상담 가이드](./security-chatbot-user.md)를 보세요.

---

## 1. 열기

1. 어느 화면이든 오른쪽 아래 **말풍선 아이콘**을 누릅니다.
2. 「일반 상담」탭이 기본입니다.
3. 창을 다시 닫으려면 헤더의 X 또는 아이콘을 한 번 더 누릅니다. **창을 닫는 것은 취소가 아닙니다.** 답은 계속 만들어집니다.
4. 챗봇 **왼쪽 위 아이콘**(또는 「사용법」칩)을 누르면 이 안내를 창 안에서 볼 수 있습니다.

---

## 2. 지금 보고 있는 화면으로 묻기

지금 열려 있는 페이지(Main, Dashboard, Issue 등)의 데이터를 기준으로 질문하세요.

- 목록·카드·버튼을 누른 뒤 질문하면 그 항목을 우선 참조합니다.
- 아래 칩을 바로 쓸 수 있습니다.
  - **사용법** — 왼쪽 위 아이콘과 같이, 이 안내를 창 안에서 엽니다.
  - **이 화면 요약** — 지금 화면 데이터를 한 번에 요약합니다.
  - **불량률 감소 방안 추천** — 설비 소프트 조치 카드를 띄우고 **승인/거절**합니다 (로그만, 기기 조작 없음). 승인·거절 후 **5초 안에 취소**할 수 있습니다.
- **이슈 ID(`ISS-…`)로 현황을 물은 뒤** 「해결방안」「조치」를 물어도 같은 소프트 조치 카드가 뜹니다.

---

## 3. 창을 닫아도 답은 계속

질문을 보낸 뒤 창을 닫아도 서버는 답을 만듭니다.

- 답이 끝나면 아이콘에 **빨간 점**이 뜹니다.
- 아이콘을 다시 열면 그 답이 대화에 보입니다.

다른 메뉴로 이동해도 챗봇은 앱 안에 그대로 있습니다.

---

## 4. 이 질문만 취소하려면

답을 기다리는 동안 **말풍선 오른쪽 위 X**를 누릅니다. (`이 대화 취소`)

- 화면에는 「대화가 취소되었습니다.」가 나옵니다.
- 이미 서버에 저장된 답이 있어도 **화면에서는 숨깁니다.**
- 헤더의 창 닫기 X와 다릅니다. 창 닫기는 취소가 아닙니다.

「새 대화」는 다른 스레드로 넘어갑니다.

---

## 5. 보안 상담이 필요할 때

비밀번호, API 키, 인증 토큰, 개인정보는 넣지 마세요.  
기밀 문서는 같은 창의 **「보안 상담」**탭으로 전환하세요. → [보안 상담 가이드](./security-chatbot-user.md)
