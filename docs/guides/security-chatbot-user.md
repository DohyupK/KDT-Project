# 보안 상담 챗봇 — 사용자 가이드

최종 갱신: 2026-08-19

같은 챗봇 창의 **「보안 상담」**탭 사용법입니다.  
일반 화면 데이터·공개 문서는 [일반 상담 가이드](./general-chatbot-user.md)를 보세요.

운영(워커 기동 등)은 [`security-chatbot-guide.md`](../references/security-chatbot-guide.md)를 보세요. 이 문서는 화면 따라 하기만 다룹니다.

---

## 1. 보안 상담으로 전환

1. 오른쪽 아래 아이콘으로 챗봇을 엽니다.
2. 상단에서 **「보안 상담」**을 누릅니다.
3. 기밀·보안 문서에 대해서만 질문하세요. 일반 화면 요약·LOT 숫자는 일반 상담이 맞습니다.
4. 챗봇 **왼쪽 위 아이콘**을 누르면 이 안내를 창 안에서 볼 수 있습니다.

비밀번호, API 키, 인증 토큰, 개인정보는 입력하지 마세요.

---

## 2. 출처

답에 **출처**가 붙을 수 있습니다. 전체화면으로 확대하면 문서 조각을 열어 볼 수 있습니다.  
문서에 없는 내용은 지어내지 않습니다. 출처가 없으면 그렇게 안내합니다.

---

## 3. 창을 닫아도 답은 계속

질문을 보낸 뒤 창을 닫아도 답은 계속 만들어집니다.

- 답이 끝나면 오른쪽 아래 아이콘에 **빨간 점**이 뜹니다. (일반·보안이 같은 아이콘입니다.)
- 다시 열면 보안 상담 탭에서 그 답을 볼 수 있습니다.

창을 닫는 것은 취소가 아닙니다.

---

## 4. 이 질문만 취소하려면

답을 기다리는 동안 **말풍선 오른쪽 위 X**를 누릅니다. (`이 대화 취소`)

- 화면에는 「대화가 취소되었습니다.」가 나옵니다.
- 이미 저장된 답이 있어도 **화면에서는 숨깁니다.**
- 「새 대화」는 다른 스레드로 넘어갑니다.
