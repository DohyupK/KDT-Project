## 적용 내용

### EXPLAIN (`secure_prompts.py` · `secure_graph.py`)

- `EXPLAIN_INSTRUCTION_SUFFIX`: 발췌 기준 공정·수치·조치 개조식 ≤3줄
- `is_explain_intent` / `wants_explain_suffix` (길이 ≤24 · not summary · hits≥1)
- `node_generate`·스트림 generate: summary → SUMMARY · elif explain → EXPLAIN
- `SECURE_GENERATE` 분기 · diversify · prior · `[SYS_RAG_EMPTY_RESULT]` hard override **유지**

### SSE (`stream_secure_chat` · FastAPI · Express · FE)

| 구간 | 경로 |
|------|------|
| FE | `postSecurityChatStream` → `/api/security-chat/stream` |
| Express | 패스스루 + `req.on('close')` → AbortController |
| ai-service | `POST /security-chat/stream` → `compose_secure_stream` |

이벤트: `meta` · `delta` · `replace`(EMPTY + sources=[]) · `done` · `error`

### Edge case 방어

1. **DB 단일 책임**
   - MariaDB `user_chat_*`: ai-service만 (user=스트림 전 1회 · assistant=`done`/`replace` 후 1회 · disconnect 시 assistant 스킵)
   - 레거시 Express `chat_store`: 패스스루 중 `\n\n` 완전 SSE 블록만 파싱 후 `done`/`replace`에서 `insertMessage` 1회
2. **통제 토큰 스마트 버퍼**: `raw` 접미사 ↔ `NO_DOC_TOKEN` 접두사 역순 partial match 홀드 → 완성 시 `replace` 즉시 종료
3. **Disconnect / error**: `request.is_disconnected()` · Express abort · 예외 시 `event: error`

## 핫픽스 (동일일 · 쿼리 오염 · 속도)

### 원인
- `"EDA 분석 결과"` 등이 `is_short_followup` 길이·토큰 휴리스틱에 걸려 `query_expanded=True` (직전 질문 병합)
- `SECURE_VLLM_MAX_TOKENS=1024` + EXPLAIN/SUMMARY → 로컬 gemma 디코드 ~30–50s
- retrieve/rerank ~5s 동안 SSE 무응답

### 조치 (초기)
- `is_short_followup` → **FOLLOWUP_RE만** (길이/토큰 휴리스틱 제거)
- EXPLAIN/SUMMARY → `make_vllm(max_tokens=256)`
- SSE 조기 `meta stage=retrieve`

### FE 말풍선 덮어쓰기 (동일일)

- **원인:** `send()`에서 user/ai를 연속 `setMessages`할 때 updater 안에서 `idRef.current`를 읽어, React 배치 시 **같은 id**가 부여됨 → delta/done이 user 말풍선까지 갱신
- **수정:** `userId`/`aiId`를 setState 전에 로컬 상수로 고정 · 스트림 갱신은 `m.role === 'ai'`만

## RAG 품질 핫픽스 (동일일 · soft fallback · FOLLOWUP_RE)

검증 후 안정 동작 확인. **도메인 명사(EDA 등) 하드코딩은 사용하지 않음.**

### 1) Rerank soft fallback — `rag_engine.py` `_rerank`

- `min_score` 컷오프는 유지
- 컷 후 `results`가 비고 `fused`(RRF)가 남아 있으면 상위 **1–2건**을 `source_dict_from_hit`으로 래핑해 반환
- 문서당 최대 2건 diversify 캡 유지
- 로그: `[secure-rag] rerank soft_fallback n=... max_score=...` (3단계에서 `max_score` 추가)

### 2) `FOLLOWUP_RE` 교정 — `secure_prompts.py`

- 제거: `그럼` · `그래서` · `그러면` · `관련` · `이어서` (화제 전환 + 신명사 → 쿼리 확장 오탐)
- 유지·보강: `그게` · `그거` · `왜` · `자세히` · `더 알려` · `이유가` · `장단점` 등 문맥 의존 표현만
- 예: `그럼 EDA 분석…` → `query_expanded=False`

### 변경 파일 (품질 핫픽스)

- `ai-service/agent/rag_engine.py`
- `ai-service/agent/secure_prompts.py`

### 건드리지 않은 것

- `fillThreshold` · `SECURE_GENERATE` 시그니처 · 0건 prior 폴백 · SSE 버퍼/제너레이터
