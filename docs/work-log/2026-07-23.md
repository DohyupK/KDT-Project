## 1. train_pipeline.py Production 고도화 (v1.1.0)

| 항목 | 내용 |
|------|------|
| 로깅 | `logs/train.log` + 콘솔 |
| GC | Optuna objective `gc.collect()` |
| metadata | version·train_date·dataset_hash·python_version·`feature_types` |
| CV | `TimeSeriesSplit` + 시간순 holdout 80/20 |
| Optuna | XGB `gamma`/`scale_pos_weight` 탐색, Cat `border_count` |
| Threshold | Cost=`FP+FN*10` → `ensemble_config.default_threshold` |
| predict | 스키마 드리프트 방어, Lazy cache |
| SHAP | CSV + JSON |

유지: `train_model`, `predict(df, fillThreshold=0.5)`, Polars.
