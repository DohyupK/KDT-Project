## 10. 버그 수정 · 시나리오 스모크 · 세션 스토어 (오후)

### 수정

| 항목 | 내용 |
|------|------|
| `backend/src/db.ts` | `import mariadb from 'mariadb'` 문법 오류 수정 → Express 기동 |
| 세션 스토어 | MariaDB root 비밀번호 없음 → `CHAT_STORE=sqlite` (영속 카운팅). `memory` / `mariadb`도 지원 |
| 유사 질문 | **연속 streak** Jaccard ≥ 0.8, 3회 이상 → `need_guideline` |
| 보안 게이트 | `사내 기밀` 등 키워드 보강, 응답 `ai_proxied: false`, ai-service `chat_requests`로 미호출 증명 |
| template 문장 | predict 결과를 더 자연스러운 한국어로 포장 (LLM 키 없을 때) |
| models | 로컬 `OPTUNA_TRIALS=2` 스모크 학습으로 `models/` 복구 (100-trial과 별개) |
