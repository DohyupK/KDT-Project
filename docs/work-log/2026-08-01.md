# 작업 일지 — 2026-08-01

## 요약

보안 챗봇 RAG를 **자연 흐름 라우팅 + 제어 토큰 + 다문서 다양성** 기준으로 정리·안정화했다.  
일반 챗(클라우드 LLM·predict 헤드)과 보안 챗(로컬 vLLM·Qdrant)은 계속 분리한다.  
`SECURE_GENERATE` / `fillThreshold` / `no_docs` 게이트는 유지.

상세 운영·스택: [`docs/references/secure-rag.md`](../references/secure-rag.md) · [`docs/references/security-chatbot-guide.md`](../references/security-chatbot-guide.md)

## 오늘 적용한 패치 (분야별)

### 검색 · 리랭크 (`agent/rag_engine.py`)

- Hybrid(dense BM25 + RRF) → `bge-reranker-v2-m3`
- **문서 다양성:** 동일 `doc_id`당 최대 2청크 → 점수 내림차순 재정렬
- `rerank_top_n=6`

### 라우팅 (`agent/secure_graph.py`)

- **자연 흐름:** 요약 의도여도 retrieve 스킵하지 않음
- 짧은 follow-up / 짧은 요약어 → 쿼리 확장; 0건이면 `prior_sources` 폴백
- 주제 전환 + 0건 → `no_docs` (엉뚱한 prior 금지)

### 출처 · 제어 토큰 (`secure_prompts.py`)

- 토큰: `[SYS_RAG_EMPTY_RESULT]` (본문 **포함** 검사)
- 감지 시 **hard override** → 고정 문구 + `sources=[]` (칩 제거)
- 정상 답: LLM `[출처:]` strip 후 실제 sources title만 강제 부착

### 요약

- generate: RAG 발췌 + 요약일 때만 단답형 `SUMMARY_INSTRUCTION_SUFFIX`
- `SECURE_GENERATE=0`이면 extractive/compressed (LLM 미호출)

### 인덱스 · 듀얼 엔진

- 옛 CSV 풀 MD 삭제·재ingest (`scripts/rebuild_secure_rag_clean.py`)
- PDF/TXT → convert MD · CSV/XLSX → `csv_lake` + `*-profile.md` + watchdog

### 프론트

- `SecurityChatbot`: `doc_id` 칩 dedupe · 문서별 다중 청크 패널 (페이지·Maximize 공통)
