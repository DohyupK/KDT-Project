# 작업 일지 — 2026-08-01

## 요약 (ai-service 보안 RAG 패치)

보안 챗 retrieve·cite·요약·인덱스를 다듬어 후속질문 매몰·가짜 출처·원문복붙 요약을 완화했다. `SECURE_GENERATE` / `fillThreshold` / `no_docs` 라우팅은 유지.

## 분야별 패치

### 1. 검색 · 리랭크 (`agent/rag_engine.py`)

- Hybrid retrieve 후 `bge-reranker-v2-m3` 점수 부여
- **문서 다양성:** 동일 `doc_id`(없으면 title)당 **최대 2청크**
- 최종 hits **점수 내림차순 재정렬** (명시적 `sort`)
- `node_retrieve` 쪽 `rerank_top_n=6`과 맞춰 다문서 여유

### 2. 후속 질문 · 라우팅 (`agent/secure_graph.py` + `secure_prompts.py`)

- 짧은 follow-up: 직전 user 질의와 **쿼리 확장** 후 검색
- 확장 검색 0건 + follow-up 패턴 → `prior_sources` 재사용
- 주제 전환 + 0건 → `no_docs` (엉뚱한 prior 미부착)
- **요약 의도:** retrieve 스킵, prior 청크는 출처용으로 유지

### 3. 출처 · `[SYS_RAG_EMPTY_RESULT]` (`secure_prompts.py` / `secure_graph.py`)

- 제어 토큰: `[SYS_RAG_EMPTY_RESULT]` (본문 **포함** 검사)
- 감지 시 hard override → 고정 문구 `EMPTY_RAG_REPLY` · **`sources=[]`** (칩 제거)
- 한국어 거절 정규식 없음 · 출처 강제 스킵

### 4. 요약 · 자연 흐름 (`secure_graph.py`)

- 요약 의도여도 retrieve 스킵하지 않음 (쿼리 확장 + 0건 시 prior 폴백)
- generate는 RAG 발췌 컨텍스트 + 요약일 때만 단답형 suffix 추가
- `SECURE_GENERATE` 분기 유지

### 5. 인덱스 · 듀얼 엔진 (이전~당일)

- 옛 CSV 풀 MD 삭제 후 SOP(+의도 MD) 재ingest (`scripts/rebuild_secure_rag_clean.py`)
- CSV/XLSX → `csv_lake` + profile MD / PDF·TXT → convert MD + watchdog

### 6. 프론트 (보안 챗 UI — 참고)

- `SecurityChatbot`: `doc_id` 칩 dedupe, 문서별 다중 청크 패널  
  (페이지·전체화면 embedded 공통)

## 건드리지 않은 것

- `fillThreshold` 시그니처
- `SECURE_GENERATE` on/off 정책 자체
- `no_docs` 게이트·오프라인 템플릿
