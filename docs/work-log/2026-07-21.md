- 원본: `c:\Users\OWNER\Downloads\KDT-Project` (Vite + React)
- 대상: `dataset/KDT-Project/frontend` (Next.js App Router)

## 마이그레이션 내용

### 프레임워크 / 라우팅

- Vite, react-router-dom을 제거하고 Next.js App Router로 전환했습니다.
- `src/App.tsx`, `src/main.tsx`는 Next.js 라우팅으로 대체되어 이전하지 않았습니다.
- Tailwind CSS는 `@tailwindcss/vite` 대신 `@tailwindcss/postcss`로 구성했습니다.
- 개발 서버 주소를 `http://localhost:5173`에서 `http://localhost:3000`으로 변경했습니다.

### 공유 모듈 이전 (무손실)

- `src/api/` — axios 인스턴스(`baseURL: '/api'`) 및 페이지별 API 스텁
- `src/data/tsData.ts` — 가상 데이터 뼈대
- `src/types/index.ts` — `AppData.fillThreshold` 필드명 보존
- `src/assets/` — 정적 에셋

### 코드 변경 포인트

- ManagementPage: `react-router-dom`의 `useNavigate` → `next/navigation`의 `useRouter`
- ManagementPage / SettingPage: Client Component를 위해 `'use client'` 적용
- SettingPage: `localStorage`, `document` 접근 로직 유지
- `next.config.ts`에 `/api/:path*` → `http://localhost:3001/api/:path*` rewrites 설정
