# 2026-08-15

- **ingest 상시 아님 (SSOT):** `python ingest_secure.py` 는 Qdrant `secure_docs` 를 한 번 채우는 작업. 표: [`documents-watcher-qdrant.md`](../references/documents-watcher-qdrant.md) §6.
- **보안 챗 = DB 큐 + PC 워커:** AWS는 `USER_SECURITY_MESSAGES`에 질문만. 이 PC `run_security_worker.py`가 검색+vLLM 후 assistant를 씀. 일반 챗은 `USER_CHAT_*`. UI는 플로팅 「보안 상담」만 (`/security` 페이지 챗 제거). 가이드: [`security-chatbot-guide.md`](../references/security-chatbot-guide.md). DDL: `python DB/ai-service/apply_user_security_tables.py` (DB 적용은 승인 후).
- **vLLM `ssh -R` 턴널 제거:** `scripts/vllm-tunnel.ps1` 삭제. 이 PC 원샷은 [`scripts/security-pc.ps1`](../../scripts/security-pc.ps1) (`:8001` 확인 · 선택 `ssh -L 3306`/`6333` · 워커). AWS `npm run dev`와 별개.
- **기동 명령 분리:** AWS `npm run dev` = 앱(워커 없음). 이 PC `npm run security-pc` = 워커만. UI는 SSE와 GET `USER_SECURITY_MESSAGES` 폴링 중 먼저 오는 쪽으로 답을 띄움. 이 PC `.env`는 터널 동안 `DB_HOST=127.0.0.1`.
- **운영 매뉴얼:** [`guides/aws-pc-security-worker.md`](../guides/aws-pc-security-worker.md) (두 명령 · `.env` · ssh `-L` · 최초 DDL/ingest · 장애).
