# 2026-07-24 프로젝트 작업 기록

## 변경 요약

API 키는 코드·GitHub에 넣지 않고 **`ai-service/.env`만** 사용하도록 정리하고,  
일반 챗봇 LLM을 **메시지 길이 기준**으로 Grok → Gemini → GPT 라우팅하도록 바꿨다.

## 1. 안전 주입

- [`ai-service/.env.example`](../../ai-service/.env.example) — 변수명·임계값만 (실키 없음)
- [`ai-service/app/main.py`](../../ai-service/app/main.py) — 기동 시 `load_dotenv(ai-service/.env)`
- README에 `.env` 복사·키 채팅 금지 안내

## 2. 길이 라우팅 (`agent/llm.py`)

| 사용자 message 길이 | 프로바이더 |
|---------------------|------------|
| ≤ `CHAT_LEN_GEMINI`(150) | Grok (xAI, `XAI_API_KEY` / `GROK_API_KEY`) |
| 151–`CHAT_LEN_GPT`(300) | Gemini (`GOOGLE_API_KEY`) |
| > 300 | OpenAI GPT (`OPENAI_API_KEY`) |

실패·키 없음 → template (구간 간 페일오버 없음).  
기존 `CHAT_LLM_PRIORITY` / NVIDIA 일반 챗 경로 제거.

## 3. Groq/Gemini 라우팅 + 100-trial 복구

- `gsk_` 키 = **Groq** (xAI Grok 아님) → `.env` 변수명 `GROQ_API_KEY`
- GPT/xAI 경로 제거
- 라우팅: ≤300 Groq(Llama) · 301–500 Gemini Flash · >500 Gemini Pro · Gemini 실패 시 Groq+안내
- Optuna `OPTUNA_TRIALS=100` 재학습으로 `models/` 복구 (2-trial 스모크 덮어쓰기 보정)
- 학습 결과: `test_roc_auc` ≈ **0.9404**, `applied_eval_threshold` **0.4** (`models/metadata.json`)
- 스모크: 짧은 메시지 → `mode=llm` / `provider=groq`; 중문(301자) → Gemini 429 후 Groq 폴백 + `[안내]` 문구 확인
