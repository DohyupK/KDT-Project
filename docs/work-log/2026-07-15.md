# 2026-07-15 프로젝트 작업 기록

## 프로젝트 초기 구성

- React 19, TypeScript 6, Vite 8 기반 프론트엔드 프로젝트를 생성했습니다.
- Axios, Day.js, Lucide React, React Router DOM, Recharts, Zustand를 설치했습니다.
- Tailwind CSS, ESLint, Prettier, Oxlint 등 개발 도구를 구성했습니다.
- `npm run dev`, `npm run build`, `npm run lint`, `npm run preview` 스크립트를 구성했습니다.
- 프로젝트 소개, 기술 스택, 개발 환경, 목표를 `README.md`에 정리했습니다.

## 프론트엔드 디렉토리 구조

- `src/pages/`에 8개 독립 페이지의 최소 컴포넌트를 생성했습니다.
  - `MainPage.tsx`
  - `DashBoardPage.tsx`
  - `LoginPage.tsx`
  - `IssuePage.tsx`
  - `InquiryPage.tsx`
  - `KnowledgePage.tsx`
  - `ManagementPage.tsx`
  - `SettingPage.tsx`
- `src/components/` 아래에 `common`, `layout`, `main`, `dashboard` 디렉토리를 생성했습니다.
- 모든 페이지는 UI와 복잡한 로직 없이 이름만 표시하는 최소 뼈대로 작성했습니다.
