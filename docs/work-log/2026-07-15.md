# 2026-07-15 프로젝트 작업 기록

## 프로젝트 초기 구성

- React 19, TypeScript, Vite 기반 프론트엔드 프로젝트를 생성했습니다.
- Axios, Day.js, Lucide React, React Router DOM, Recharts, Zustand를 설치했습니다.
- Tailwind CSS, ESLint, Prettier 등 개발 도구를 구성했습니다.
- 프로젝트 소개, 기술 스택, 개발 환경, 목표를 `README.md`에 정리했습니다.

## 프론트엔드 디렉토리 구조

- `src/pages/`에 8개 독립 페이지의 최소 컴포넌트를 생성했습니다.
  - `MainPage.tsx`
  - `DashBoardPage.tsx`
  - `LoginPage.tsx`
  - `IssuePage.tsx`
  - `InquiryPage.tsx`
  - `KnowledgePage.tsx`
  - `ManagementPage.tsx`
  - `SettingPage.tsx`

## 페이지 라우팅

`src/App.tsx`를 8개 페이지의 라우팅 전용 컴포넌트로 구성했습니다.

- `/` → MainPage
- `/dashboard` → DashBoardPage
- `/login` → LoginPage
- `/issue` → IssuePage
- `/inquiry` → InquiryPage
- `/knowledge` → KnowledgePage
- `/management` → ManagementPage
- `/setting` → SettingPage

## API, 타입 및 데이터 뼈대

- `src/api/axios.ts`에 `/api`를 기본 경로로 사용하는 Axios 인스턴스를 생성했습니다.
- 페이지별 API 뼈대 파일을 생성했습니다.
- `src/types/index.ts`에 `fillThreshold: number` 필드를 보존한 `AppData` 인터페이스를 생성했습니다.
- `src/data/tsData.ts`에 예측 시뮬레이션용 가상 데이터 배열의 뼈대를 생성했습니다.
