## 3. 인수인계 → `handover_history` → Knowledge

### 최종 흐름 (08-04 말 기준)

```text
인수인계 사항 등록
  → issues에 ISS-yyMMdd-NNN 자동 INSERT (LOT-SYS-HANDOVER)
  → handover_history INSERT (action NULL, history_id=AUTO_INCREMENT)
  → Issue「교대 전달」에 pending 공유 (전 로그인 사용자)

항목「완료」(보고서)
  → PATCH …/handover/:historyId/complete → action='완료'
  → Knowledge「인수인계 이력」GET status=completed
```

### DB

- `uk_handover_issue` UNIQUE 제거 (이슈당 다행) — 마이그레이션: [`DB/migrate_handover_drop_unique.sql`](../../DB/migrate_handover_drop_unique.sql) · 스크립트 [`backend/scripts/migrate-handover-drop-unique.ts`](../../backend/scripts/migrate-handover-drop-unique.ts) (원격 적용됨)
- `action` 컬럼을 완료 플래그로 사용: `NULL`=pending, `'완료'`=Knowledge
- 본문 = `situation`

### API

| 메서드 | 경로 | 역할 |
|--------|------|------|
| POST | `/api/knowledge/handover` | 등록 (issueId 불필요, 서버 채번) |
| GET | `/api/knowledge/handover-history?status=pending\|completed` | 목록 |
| PATCH | `/api/knowledge/handover/:historyId/complete` | 항목 완료 |
| PUT | `/api/issues/:id` (완료) | 해당 issue pending 행 `action='완료'` UPDATE (유지) |

### 채번

| 컬럼 | 규칙 |
|------|------|
| `issues.issue_id` | `ISS-` + `yyMMdd` + `-` + `001`… (일별, 정규식 3자리만) |
| `handover_history.history_id` | MariaDB `AUTO_INCREMENT` |

- 구문 오류: `knowledge/page.tsx` 중복 `];` 제거
