## 대시보드 · 생산 상세 실데이터 · 최근 7일

**상태:** `getProductionDaily` 재작성 · FE 컬럼·필터 반영.

### 집계 규칙

| 컬럼 | 소스 |
|------|------|
| 날짜 | `lots.id` `LOT-YYYYMMDD-…` → `YYYY-MM-DD` (실패 시 `timestamp` 폴백) |
| 총생산량 | 당일 LOT **행 수** |
| 양품 / 불량 | `probability < 0.8` / `>= 0.8` · **NULL은 양품·불량 제외, 총생산에는 포함** |
| 불량률 | 불량수 / 총생산량 |
| 금속 불순물·소성 온도·습도·리튬 투입량·첨가제 비율·압력·공정시간 | 당일 LOT **평균** · 컬럼 NULL은 **평균에서 제외**(전부 NULL이면 `null`/`-`) |

- 기간: 최신 lot_id 날짜 기준 **최근 7일** (기본 1페이지·최대 7행)
- 제거: `소성온도×습도`, `temp_dev_from_800`(이탈)
- 이름: 소성온도 이탈 → **소성 온도** (`sintering_temp` AVG)
- 필터: `operatorId`, `d50`/`d90` min·max — 개별 또는 동시 **AND** · 아이콘+입력 UI
- CSV 체크박스 다운로드(`lots.csv?date=`) 유지
