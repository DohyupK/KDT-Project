## 5. 단계 진단 로그

관련 질의만 500이고 무관 질의는 `security_no_docs`인 패턴 → 진단 강화.

- ai-service: `trace[]` (retrieve / gate / generate) · unhandled → JSON 500
- BE: `{ error, stage, trace, elapsed_ms }` · 502/504
- FE: 「연결 실패」고정 문구 제거 → **stage/trace 블록** + `console.warn`

미재시작 시 UI에 `HTTP 500` + axios 기본 메시지만 남는 경우 있음 → **backend·frontend·ai-service 재시작** 필요.

## 6. 관련 질의 500 최종 안정화 (`SECURE_GENERATE=0`)

| 질의 | 결과 |
|------|------|
| 무관 (점심 등) | `security_no_docs` OK |
| 관련 (슬러리/코팅) | Gemma generate 지연 → 프록시 **500** |

**조치:**

- `.env` **`SECURE_GENERATE=0`** (기본): 히트 시 LLM 생략 → 문서 발췌 + `[출처:]` · `provider=rag_extractive` · HTTP **200**
- `SECURE_GENERATE=1`이면 generate 시도 · 실패/타임아웃 시에도 extractive 폴백
- `SECURE_VLLM_TIMEOUT` 기본 **45s** · `SECURE_VLLM_MAX_TOKENS` 제한

검증: 코팅 질의 ~20s · `mode=security_rag` · `sop-coating-v1` · 200.

UI에 보이는  
「로컬 LLM 생성을 건너뛰고… (SECURE_GENERATE=0)」  
문구는 **의도된 안내** (요약 끄고 발췌만 제공).
