# 양극재 소성공정 SOP v1.2 (내부)

## 목적
소성로 온도·유지 시간을 표준화하여 용량 편차와 잔여 리튬 이상을 줄인다.

## 표준 조건
- 목표 소성 온도: 780–820°C (권장 800°C)
- 유지 시간: 8–12시간
- 승온 속도: 2°C/min 이하

## 이상 시 조치
1. 온도가 820°C를 초과하면 즉시 가열 출력을 낮추고 로트 기록을 남긴다.
2. 습도가 동반 상승한 경우 humidity SOP를 병행 확인한다.
3. 잔여 리튬이 공정 상한을 넘으면 리튬 투입비 재검토를 요청한다.

## 보안
본 문서는 사내 내부용이다. 외부 반출을 금지한다.
