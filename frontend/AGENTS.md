## Frontend 추가 규칙

- 페이지는 App Router 기준: `src/app/**/page.tsx`
- `src/types`의 `AppData.fillThreshold` 필드명·의미는 바꾸지 않는다
- 화면 상세 절차는 개별 룰·스킬을 따른다 (예: Setting → `responsive-layout` / `setting-page`)
- 작업 방향·일지는 루트 `docs/`에 둔다 (`docs/direction.md`, `docs/work-log/`)
